CHALLENGERS

To play:
1. Extract the entire Challengers folder from this ZIP.
2. Open index.html in a modern web browser.
3. Choose a mode and difficulty, then press Start Challenge.

Keep index.html, style.css, script.js, and words.js in the same folder.
No installation, server, libraries, or build tools are required.

Included database: 375 entries across 25 themes; 15 per theme.
Each theme contains 3 easy, 6 medium, and 6 hard answers.
The original 1,250-word database target is not yet complete.

Scores and sound preferences are stored in the current browser when
local storage is available. Clipboard and storage features can behave
differently when opening local files; the game includes fallback handling.

To add words, edit the matching addTheme section in words.js.
Use the documented entry format and supply all three clues and a fact.
Avoid duplicate answers and clues that reveal the answer or its aliases.
